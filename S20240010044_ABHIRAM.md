## 1. Executive Summary

In the development of **CareerNest**, my primary contribution focused on engineering the **complete Recruiter Portal (React SPA)**, encompassing end-to-end recruitment lifecycle workflows, candidate evaluation engines, job posting systems, interview scheduling, and full-stack API integration:

- **Recruiter Command Center (`RecruiterApp.jsx`, `Dashboard.jsx`)**: Built the primary recruiter workspace featuring high-level hiring KPI cards (Posted Jobs, Total Applicants, Shortlisted, Alumni Referrals), background polling for live applications and notices, and quick-action navigation paths.
- **Job Posting & Opportunity Lifecycle (`PostOpportunity.jsx`, `MyOpportunities.jsx`)**: Engineered a comprehensive job drafting engine equipped with strict real-time regex validators (title, compensation format, eligibility, deadlines), multi-branch selectors, and an active job directory with inline editing and publication status toggling (`Published` / `Closed`).
- **Applicant Tracking System & Pipeline Management (`Applications.jsx`, `CandidateModal.jsx`)**: Designed an interactive candidate pipeline supporting real-time search, multi-role dropdown slicing, status tab filtering, and alumni referral attribution badges. Built an in-depth evaluation modal featuring resume viewing, star ratings across core competencies, locked sequential stage progression, and direct candidate feedback dispatch.
- **Candidate Screening Queue & Bulk Actions (`CandidatesFilter.jsx`)**: Developed a fast-track screening console for pending applicants, allowing recruiters to filter by minimum CGPA, department, and referral status, and execute bulk shortlisting or bulk rejections in a single API call.
- **Interview & Assessment Coordination (`Assessments.jsx`, `ScheduleModal.jsx`)**: Built the assessment management hub for coding tests and technical rounds, with modal-based scheduling, Google Meet link normalization, and direct target mapping (individual candidate vs. entire role cohort).
- **Hiring Analytics & Visual Recruitment Funnel (`HiringReport.jsx`)**: Implemented dynamic recruitment funnel visualizations tracking candidate throughput from application to offer release, alongside departmental and role-based application distributions.
- **Supporting Backend Engine (`backend/backend/`)**: Developed and connected backend NestJS microservices and REST endpoints across opportunities, applications, assessments, and recruiter verification modules.

## 3. Detailed React Frontend Contributions & File Breakdown

### A. Recruiter Portal Shell & Orchestration (`React/React/src/roles/recruiter/`)

1. **`RecruiterApp.jsx` (Portal Root Shell & Master State Orchestrator)**:
   - Coordinates navigation across all 8 recruiter tabs (`dashboard`, `post`, `opportunities`, `applications`, `assessments`, `candidates`, `reports`, `profile`).
   - Integrates `navigationState.js` (`readSavedPage`, `savePage`) to maintain active tab position across browser refreshes.
   - Synchronizes live data concurrently on mount via `fetchRecruiterData()` using `Promise.all()`.
   - Executes periodic background polling every 20 seconds to pull fresh applications and unread notifications while the tab is active.
   - Computes live applicant counts per opportunity (`opportunitiesWithCount`) using `useMemo` to eliminate unnecessary re-computations.
   - Manages top-level toast alert lifecycles (`showToast`) and handles secure session termination via `SignOutModal`.

2. **`components/Navbar.jsx` (Header Bar, Live Notifications & User Menu)**:
   - Dynamic page title display reflecting the active workspace view.
   - Notification popover with unread counter badge (`9+` formatting) and async "Mark all read" dispatch.
   - User account dropdown with initials avatar badge, company affiliation, profile navigation shortcut, and sign-out trigger.
   - Click-outside event listeners (`useRef` + `useEffect`) to seamlessly dismiss popovers.

3. **`components/Sidebar.jsx` (Responsive Navigation Drawer)**:
   - Sidebar navigation featuring branding (`CareerNest — Recruiter Portal`), recruiter avatar badge, and dynamic active-tab highlights powered by `lucide-react` icons.
   - Integrated sign-out button opening confirmation modal.

4. **`components/SignOutModal.jsx` (Accessible Sign-Out Dialog)**:
   - Modal overlay with `role="dialog"` and `aria-modal="true"`.
   - Cleanly purges authentication tokens and redirects user to `/login`.

### B. Opportunity Creation & Lifecycle Management (`React/React/src/roles/recruiter/components/`)

1. **`components/PostOpportunity.jsx` (Job Posting & Controlled Validation Form)**:
   - Multi-field controlled job creation form: Job Type (`Full-Time` / `Internship`), Title, Location, CTC/Stipend, Openings, CGPA cut-off, Deadline, and Description.
   - **Real-Time Client-Side Validators**:
     - *Job Title*: Alphanumeric, spaces, and hyphens; strictly rejects purely numeric or hyphen-only strings.
     - *Compensation (CTC)*: RegEx pattern matching (`10-14 LPA`, `14 LPA`, `35000/month`, `₹35,000/month`).
     - *Openings*: Enforces positive integers (>= 1).
     - *Deadline*: Restricts selection to today or future calendar dates.
     - *Skill Chips*: Dynamic tag management allowing recruiters to add/remove custom skill pills with alphanumeric validation.
     - *Eligible Branches*: Multi-select toggle pills (`CSE`, `ECE`, `IT`, `EEE`, `MECH`, `CIVIL`).
   - Dispatches validated payload to `api.post('/opportunities')` and redirects recruiter to the Opportunities tab upon success.

2. **`components/MyOpportunities.jsx` (Opportunity Directory & Status Governance)**:
   - Renders interactive cards for all posted openings with real-time applicant counts.
   - **Live Status Toggle**: One-click publication toggle (`Published` <-> `Closed`) updating the backend instantaneously.
   - **Inline Edit Modal**: Controlled modal allowing recruiters to update job details, deadlines, and requirements without leaving the directory.
   - Opportunity deletion workflow with confirmation prompt.
   - Contextual navigation shortcut that presets the role filter in the Applications tab for instant applicant inspection.

### C. Applicant Tracking System (ATS) & Candidate Evaluation (`React/React/src/roles/recruiter/components/`)

1. **`components/Applications.jsx` (Applicant Pipeline & Filter Hub)**:
   - Real-time text search across candidate names, branches, and applied roles.
   - Role filter dropdown dynamically populated with unique roles from current applications.
   - "Referred Only" toggle filter highlighting alumni-endorsed applicants.
   - Status stage filter pills (`All`, `Applied`, `Shortlisted`, `Assessment`, `Interview`, `Offered`, `Rejected`) displaying live candidate counts.
   - **Candidate Application Cards**:
     - Candidate avatar, branch, CGPA, applied role, and application date.
     - **Alumni Referral Attribution Badge**: Renders referrer initials avatar, name, corporate designation, company, and graduation batch.
     - Contextual "Schedule" action button for shortlisted candidates.
     - Status selector triggering the in-depth `CandidateModal`.

2. **`components/CandidateModal.jsx` (Deep Evaluation, Multi-Round Pipeline & Scoring)**:
   - Comprehensive modal dialog for in-depth candidate review:
     - Profile details, resume preview and download triggers.
     - Dedicated alumni referral review panel with referrer's personal recommendation note.
   - **Multi-Round Pipeline Tracking (`ROUND_KEYS`)**:
     - Manages 4 distinct recruitment stages: `1. Resume Screening`, `2. Online Assessment`, `3. Technical Interview`, `4. HR / Behavioral Interview`.
     - **Sequential Round Locking (`isRoundLocked`)**: Automatically locks subsequent stages until the prerequisite round achieves a `Pass` state.
     - **Deterministic Status Derivation (`deriveStatus`)**: Derives overall application status dynamically based on individual round outcomes (e.g., any `Fail` -> `Rejected`; all `Pass` -> `Offered`).
   - **Competency Evaluation & Feedback**:
     - Embedded `StarRating` subcomponent for 1–5 star scoring across Technical Skills, Problem Solving, Communication, and Cultural Fit.
     - Recruiter qualitative feedback editor with async "Send Feedback to Candidate" toggle.

## 4. Supporting Backend Development (`backend/backend/`)

To deliver live data, multi-round status transitions, and bulk updates to the Recruiter Portal, I contributed to the **NestJS backend services and REST APIs**:

- **Opportunities Module (`src/opportunities/`)**:
  - `opportunities.controller.ts`, `opportunities.service.ts`, `opportunities.repository.ts`.
  - Implemented `POST /opportunities` for recruiters to submit campus job postings scoped to their company.
  - Implemented `GET /opportunities`, `PUT /opportunities/:id`, and `DELETE /opportunities/:id` for lifecycle and publication management.
- **Applications Module (`src/applications/`)**:
  - `applications.controller.ts`, `applications.service.ts`, `applications.repository.ts`.
  - Implemented `GET /applications` filtering applications specific to the recruiter's company openings.
  - Implemented `PATCH /applications/:id/status` supporting granular updates to application status, multi-round stage progression (`resume`, `assessment`, `technical`, `hr`), star evaluations, and feedback.
  - Built `POST /applications/bulk-status` to handle batch shortlisting and rejections in an atomic transaction.
- **Assessments Module (`src/assessments/`)**:
  - `assessments.controller.ts`, `assessments.service.ts`, `assessments.repository.ts`.
  - Implemented `POST /assessments` for creating virtual interview rounds and coding tests linked to applications or opportunities.
  - Implemented `GET /assessments` and `DELETE /assessments/:id` for scheduling coordination.
- **Recruiters & Users Modules (`src/recruiters/`, `src/users/`)**:
  - `recruiters.controller.ts`, `recruiters.service.ts`: Handled recruiter verification records and company onboarding.
  - `users.controller.ts`: Provided `GET /users/:id` and `PUT /users/:id` powering the recruiter's profile management.
- **Notifications & Referrals (`src/notifications/`, `src/referrals/`)**:
  - Automated notification triggers informing recruiters when candidates apply or when alumni submit referral recommendations.
