## 1. Executive Summary

In the development of **CareerNest**, my primary contribution focused on the **public authentication flow and recruiter contact experience**, specifically the **login page** and the **contact us / recruiter inquiry page**:

- **Login Page (React SPA)**: Designed and implemented a fully functional authentication screen with email/password input, password visibility toggle, client-side validation, loading states, and backend login integration.
- **Role-Based Redirect System**: Integrated the login flow with role-based routing so each user is redirected to the correct portal after successful authentication.
- **Contact Us / Recruiter Inquiry Form**: Built a polished, responsive contact form that collects recruiter information, validates inputs, fetches colleges dynamically, and submits the inquiry to the backend contact API.
- **Session Handling & Secure Navigation**: Stored the authenticated user data in browser storage and tied the flow to application route protection so only valid logged-in users access protected sections.
- **Frontend-Backend Integration**: Connected both the login and contact workflows to the NestJS backend endpoints for real data submission and response handling.

## 3. Detailed React Frontend Contributions & File Breakdown

### A. Login Page Experience (`React/React/src/public-pages/login/`)
Developed the public login screen for CareerNest to provide secure and user-friendly authentication for all roles.

#### Specific Files Developed:
1. **`LoginPage.jsx` (Authentication Interface & Redirect Logic)**:
   - Created the complete login screen with **email and password fields**, a **show/hide password toggle**, and **sign in button**.
   - Implemented backend-driven authentication by sending user credentials to the `/users/login` endpoint.
   - Stored authenticated session values in `localStorage` including `loggedInUser`, `userRole`, `userName`, `userEmail`, `userId`, and `accessToken`.
   - Added **role-based redirection** mapping each user role to the correct route, including candidate, alumni, recruiter, placement officer, college admin, and super admin.
   - Included error handling for invalid credentials and server connection failures.
   - Added a demo account section to provide a user-friendly testing experience during development.

2. **`Login.css` (Authentication Styling & Responsive Layout)**:
   - Designed the login panel with a clean card layout, branded header, form groups, password toggle, and CTA button.
   - Implemented responsive CSS for desktop and smaller viewports.
   - Styled validation and success/error message states for a professional user experience.

---

### B. Contact Us / Recruiter Inquiry Form (`React/React/src/public-pages/landing/components/`)
Built the public contact page used by recruiters to get in touch with the placement office and submit hiring requests.

#### Specific Files Developed:
1. **`ContactSection.jsx` (Recruiter Request Form)**:
   - Developed a fully controlled contact form capturing the recruiter's name, email, company, role, phone, college, and message.
   - Added input validation rules to enforce required fields and proper formatting.
   - Fetched available colleges from the backend using `/contact/colleges` and populated the dropdown.
   - Submitted recruiter details to `/contact/recruiter` API endpoint with form payload formatting and validation checks.
   - Integrated success/error status handling to show whether the request was submitted successfully or failed.
   - Reset the form after successful submission and provide option for sending another request.

2. **`LandingPage.jsx` / Landing Layout Integration**:
   - Integrated the contact form into the public landing page to ensure the recruiter inquiry section is visible and accessible to users visiting the site.
   - Maintained a consistent themed UI with the rest of the public-facing marketing pages.
