## 3. Detailed Breakdown of Contributions

### A. Alumni Actor Implementation

The Alumni Actor subsystem bridges the gap between graduating students seeking industry job referrals and alumni working at top tech firms.

#### 1. Core Architecture & Router (`AlumniApp.jsx`)
- **Single Page Navigation Orchestration:** Built a clean internal view routing system supporting `dashboard`, `directory`, `profile`, and `referrals` views using persistent state (`readSavedPage` / `savePage`).
- **Lifted State Pattern:** Lifted user profile and skills state to `AlumniApp` so edits persist seamlessly when switching between pages without losing unsaved changes.
- **Real-Time Polling Engine:** Implemented an active polling timer (`setInterval` at 20-second intervals) that queries the `/referrals` endpoint when the tab is visible (`!document.hidden`), ensuring the alumnus immediately sees incoming student requests.
- **Profile Synchronization:** Maintained synchronization between the server (`PUT /users/${session.id}`), React component state, and `localStorage` (`loggedInUser`) so changes reflect across open tabs.

#### 2. Referral Requests & Candidate Review (`ReferralRequests.jsx`, `ResumeModal.jsx`, `DeclineModal.jsx`)
- **Card-Based Application Pipeline:** Developed an expandable accordion interface detailing student background, CGPA, department, graduation year, target company, role, expected compensation, and candidate statement.
- **Candidate Summary Intelligence:** Created contextual profile summaries for applicants (e.g., candidate highlights, competitive programming ranks, tech stack proficiencies) to help alumni quickly evaluate fit.
- **Interactive Resume Modal:** Implemented an inline, component-based resume viewer (`ResumeModal.jsx`) displaying structured sections (Education, Experience, Key Projects, Skills, and Achievements) with print and download buttons, eliminating external PDF rendering issues.
- **Constructive Decline Mechanism:** Designed `DeclineModal.jsx` to mandate feedback when rejecting an application, giving students actionable advice to improve their profiles.

#### 3. Alumni Dashboard & Analytics (`AlumniDashboard.jsx`)
- **Metric Cards:** Built dynamic statistic widgets displaying real-time counts for Pending, Approved, Total, and Declined requests with visual status indicators.
- **Recent Activity Feed:** Curated an actionable stream of incoming candidate requests with instant approve/reject buttons and quick links to review resumes.

#### 4. Alumni Profile & Skills Management (`AlumniProfile.jsx`)
- **In-Place Profile Editing:** Enabled editing of role designation, company, location, and social links (LinkedIn, GitHub, Portfolio).
- **Interactive Skills Tagging:** Provided an interactive skill tag manager allowing alumni to add and remove technical competencies.
- **Security & Authentication:** Embedded password update workflows and modal integrations.

#### 5. Alumni Directory, Mentorship & Events (`AlumniDirectory.jsx`, `MentorshipHub.jsx`, `AlumniEvents.jsx`, `featuresApi.js`)
- **Directory Search & Department Filter:** Implemented search by alumni name, company, and location with short-code mapping for branches (CSE, ECE, EEE, MECH, CIV, IT, DS).
- **Mentorship Hub:** Built request tracking and response workflows for mentorship guidance.
- **Events Calendar & Registration:** Created an event showcase with dynamic registration tracking by current user ID.

#### 6. Notification System (`AlumniNotifications.jsx`)
- **Dropdown Notification Center:** Created a header bell icon with a real-time unread badge indicator.
- **Auto-Refresh & Bulk Read:** Automated 30-second interval updates and added a "Mark all read" trigger calling `PATCH /notifications/read-all`.

### B. Bulk Notifications in Placement Cell (`BulkNotify.jsx`)

The **Bulk Notifications** module allows placement officers to broadcast urgent updates, placement drive alerts, and interview schedules to specific segments of the institution.

#### Key Features Developed:
1. **Target Group Segmentation:**
   - 👩‍🎓 Students
   - 🎓 Alumni
   - 💼 Recruiters
   - 🌐 Everyone (Campus-Wide)
2. **Form Validation & Input Safeguards:**
   - Enforces non-empty Subject / Title (minimum 5 characters).
   - Enforces comprehensive Message Body (minimum 10 characters).
   - Real-time inline validation feedback preventing accidental empty broadcasts.
3. **Dispatch Pipeline & API Integration:**
   - Dispatches payloads via `POST /features/officer/notifications/bulk`.
   - Displays real-time confirmation banners with delivery timestamps and total recipient counts (e.g., *"Sent to 142 recipients at 10:30 AM"*).
4. **Historical Broadcast Log:**
   - Fetches sent announcements via `GET /features/officer/notifications`.
   - Chronologically sorts sent notifications (`sort((x, y) => sentAt)`).
   - Displays target badges, message previews, and precise dispatch timestamps for auditing.

### C. Application Tracking in Placement Cell (`AppTracking.jsx`)

The **Application Tracking System (ATS)** provides placement officers with end-to-end visibility over students and their recruitment pipelines across all visiting companies.

#### Key Features Developed:
1. **Candidate Roster & Instant Search:**
   - Retrieves candidates via `useOfficerData()` hook.
   - Live search filter matching against candidate name or college roll number.
2. **Computed Placement Status Engine:**
   - Implemented `placementStatus()` algorithm to categorize students based on their active applications:
     - **Placed:** At least one application has status `Selected`.
     - **In progress:** Candidate is `Shortlisted` or has an `Interview Scheduled`.
     - **Applying:** Candidate has active applications under review.
     - **No applications:** Candidate has not yet applied to any drive.
3. **Candidate Summary Table:**
   - Displays candidate avatar (initials generator), Name, Roll Number, Branch, Email address, and Placement Status badge.
   - Smooth keyboard accessibility (`Enter` key trigger) and click navigation to view details.
4. **Drill-Down Candidate Profile & Opportunity Drawer:**
   - Header summary showing student contact info and overall placement progress.
   - List of all opportunities applied by the student showing company icon initial, job role, company name, application submission date, and scheduled interview dates.
   - Granular status badges: `Applied`, `Under Review`, `Shortlisted`, `Interview Scheduled`, `Selected`, and `Rejected`.

## 5. Technical Highlights & Best Practices

- **Component-Driven Architecture:** Clean separation of concerns between presentation components, containers, modals, and data services.
- **Zero Heavy External Dependencies for Modals:** Custom-built accessible modals (`ResumeModal`, `DeclineModal`, `SignOutModal`) styled using native responsive CSS rather than heavy UI component libraries.
- **Defensive State & Error Handling:** Graceful fallbacks for network latency, missing properties, plan-gated 403 errors, and empty datasets.
- **Responsive & Accessible UI:** Designed with mobile-friendly breakpoints, keyboard accessibility (`onKeyDown` handlers), semantic HTML tags (`main`, `nav`, `article`, `table`), and color-coded status badges for high visual clarity.
- **Cross-Module Consistency:** Adhered strictly to the CareerNest UI design system, color palette, icon set (Lucide icons & custom SVGs), and layout frames.
