### D. Client-Side Routing & Protected Route Guards (`React/React/src/app/`)
Architected the single-page application navigation structure ensuring code-split bundles and strict role authorization.

#### Specific Files Developed:
1. **`AppRouter.jsx` (Client-Side Routing Pipeline)**:
   - Configured high-level route mapping with `react-router-dom` v7.
   - Employs **`React.lazy()`** dynamic imports for all role portals (`CandidateApp`, `RecruiterApp`, `PlacementApp`, `CollegeAdminApp`, `SuperAdminApp`, `AlumniApp`).
   - Wraps asynchronous components in **`<Suspense fallback={<RouteLoading />}>`** to ensure smooth transition states and minimal initial bundle size.
   - Encloses protected routes within a helper higher-order component `secured(role, Component)`.

2. **`ProtectedRoute.jsx` (Role-Based Route Guard)**:
   - Evaluates user authentication state from `localStorage` (`loggedInUser`).
   - Validates whether the logged-in user possesses the required `allowedRole`.
   - Automatically redirects unauthenticated traffic to `/login` and reroutes unauthorized role traffic to their respective portal home, eliminating unauthorized URL traversal.

### E. State Management & API Integration Layer (`React/React/src/shared/`, `src/services/`)
Designed the shared infrastructure that connects React components to REST endpoints and maintains live synchronization across the application.

#### Specific Files Developed:
1. **`shared/context/PlatformDataContext.jsx`**:
   - Centralized React Context providing multi-role platform state (`colleges`, `officersByCollege`, `studentsByCollege`, `stats`).
   - Implements `refresh()` with `useCallback` to query relevant endpoints concurrently using `Promise.all()`.
   - Provides mutation functions (`addOfficer`, `updateOfficerStatus`, `removeOfficer`, `addCollege`, `toggleCollegeStatus`) that update local state optimistically or synchronously upon API response.

2. **`shared/context/AuthContext.jsx`**:
   - Manages global authentication status, current user object, login handlers, and logout procedures.

3. **`services/api.js` (Unified Axios Client)**:
   - Singleton Axios instance with configurable `baseURL`.
   - **Request Interceptor**: Automatically injects session context headers (`x-user-id`, `x-role`, `x-college-id`) and Bearer tokens on every outgoing HTTP request.
   - **Response Interceptor**: Automatically intercepts `401 Unauthorized` responses, flushes stale credentials via `clearSession()`, stores a notification notice in `sessionStorage`, and redirects to `/login`.
   - Utility helper `errorMessage(error)` parsing API validation errors into readable strings for React UI toasts.

4. **`shared/utils/navigationState.js`**:
   - Stateful navigation utilities (`savePage`, `readSavedPage`) persisting active dashboard tabs across page reloads.

## 4. Supporting Backend Development (`backend/backend/`)

To provide the live data and role-based endpoints consumed by the React portals, I also built the **entire NestJS backend application**:

- **System Bootstrap & Framework Setup**: `src/main.ts`, `src/app.module.ts`, `package.json`, `tsconfig.json`.
- **Domain Modules & REST Controllers**:
  - `colleges/` — College CRUD, onboarding, and status APIs.
  - `super-admin/` — Platform stats, college admin provisioning, and broadcast messaging APIs.
  - `users/` — Authentication, role-based user directory, and profile services.

  - `notifications/` — Role-targeted notifications.
  - `activity/` — Audit logging service tracking platform actions.
  - `contact/` — Recruiter inquiry endpoint powering the Landing Page contact form.
  - `opportunities/`, `applications/`, `assessments/`, `recruiters/`, `referrals/` — Core placement workflow APIs.

  - `common/guards/roles.guard.ts` — Custom RBAC guard validating incoming headers (`x-role`, `x-college-id`).
  - `common/middleware/security.middleware.ts` — Rate limiting and security headers (CSP, Frame Options, XSS).
  - `common/middleware/logger.middleware.ts` & `log-file.service.ts` — Request logging and rotating error logs.
  - `common/filters/all-exceptions.filter.ts` — Global exception handler formatting structured JSON responses.
